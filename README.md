# Morok Web

Веб-версія месенджера Morok. Вона ж основа десктопного застосунку.

Працює у браузері без встановлення: відкрили сторінку релея — і можна
писати. Уся криптографія відбувається на вашому боці, сервер отримує
готовий шифротекст.

**Що вміє**

- Приватні чати й групи з наскрізним шифруванням
- Повідомлення, що зникають, і спалювання після прочитання
- Анонімні листи через одноразові лінки
- Номер безпеки для звірки ключів
- Пошта morok.email
- Робота з будь-яким релеєм Morok, включно зі своїм

**Десктоп**

Та сама кодова база збирається у Windows-застосунок (Tauri): трей,
згортання у фон, нативні сповіщення.

**Акаунт**

24 слова замість пароля й телефону. Ключі не залишають пристрій.
